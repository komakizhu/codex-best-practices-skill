# 统一 Workflow 交接与校验

## 目标

让六个公共 Workflow Skill 在多会话切换时都明确呈现当前状态、下一步执行者、用户可选择的动作和权限边界。等待用户时只展示当前场景真正需要的 3～4 个选项；可以继续的执行进度继续执行，不用未来时态代替交接。

## 范围

- 六个 `.agents/skills/*/SKILL.md` 及其 `agents/openai.yaml`。
- `scripts/validate-workflow-output-format.rb`、`scripts/validate-workflow-continuity.rb` 和 Ruby 回归夹具。
- `docs/codex-workflow-context.md` 与 `task-router` 的现行验收案例。
- 不修改其他独立 Skill，不新增运行时 Workflow 系统，不涉及 App 编译。
